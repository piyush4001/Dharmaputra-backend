# DharmaPutra Backend (TypeScript)

## Project Structure

```
backend-ts/
├── src/
│   ├── app.ts
│   ├── server.ts
│   ├── config/
│   ├── models/
│   ├── controllers/
│   ├── services/
│   ├── routes/
│   ├── middlewares/
│   └── utils/
├── dist/
├── .env
├── package.json
├── tsconfig.json
└── README.md
```

## Getting Started

1. Install dependencies: `npm install`
2. Configure environment variables in `.env`
3. Build the project: `npm run build`
4. Run the server: `npm start`

## Development

For development with auto-reload: `npm run dev`

For watching TypeScript compilation: `npm run watch`
